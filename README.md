# Tabview

Safari's "Show All Tabs" grid, for Finder.

- **⇧⌘\\** while Finder is in front (same shortcut as Safari), or
- **Pinch in** on the trackpad over Finder, or
- Menu bar icon → Show Finder Tabs

In the grid: click a card or press Return to switch, ✕ / ⌘W to close a tab, + for a new tab,
type to search, arrow keys to move, Esc or pinch out to dismiss.

Build & install: `./build.sh` (installs to `~/Applications/Tabview.app`).
Needs Accessibility (tab bar + pinch) and Automation → Finder (folder previews).
